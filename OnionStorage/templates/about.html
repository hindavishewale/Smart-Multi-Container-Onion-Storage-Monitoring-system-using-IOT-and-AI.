🧅 About This Project
Smart Onion Storage Monitoring System — AI + IoT
Project Overview

This is a Smart Onion Storage Monitoring System that combines Artificial Intelligence and IoT sensors to monitor onion storage conditions in real-time. The system uses an ESP8266 microcontroller with DHT11 and MQ135 sensors to measure Temperature, Humidity, and Gas levels inside storage containers. This data is sent to a Flask web server every 2 seconds, where an AI model predicts whether the storage condition is Safe, Warning, or Critical. Based on the prediction, IoT actuators (fans, dehumidifier) are automatically controlled to maintain optimal storage conditions and prevent onion spoilage.

How It Works
1 ESP8266 reads Temp, Humidity, Gas every 2 seconds
2 Sends JSON to Flask server at /predict endpoint
3 Flask derives Moisture and CO₂ ppm from raw values
4 AI model predicts: Safe / Warning / Critical
5 Decision engine triggers fans/dehumidifier
6 Dashboard updates live every 2 seconds
7 All readings saved to CSV for model retraining

Content-Type: application/json

Flask derives:

co2_ppm = (gas/1024)×800 + temp×5 → 1292 ppm

Input: [28.5, 29.0, 5.8, 1292] → Output: "Critical"

Flask returns to ESP:
Critical

ESP OLED shows:
Temp: 28.5C | Hum: 29.0% | Gas: 1471 | Risk: Critical
